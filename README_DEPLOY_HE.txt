מדריך העלאה מהיר לאינטרנט (חינם) - אפליקציית קו 411 להורים
============================================================

בחבילה זו נמצאים הקבצים המוכנים להעלאה:
1. index.html - האפליקציה המלאה בקובץ אחד עצמאי (כולל כל העיצוב, הנתונים והתמונות).
2. manifest.json - הגדרת אפליקציה לנייד (מאפשר שמירה על מסך הבית באייפון/אנדרואיד כאייקון).
3. api/bus.js - פונקציית שרת אופציונלית (עבור Vercel) לעקיפת חסימת CORS ושליפת GPS ישירה משרתי האוטובוסים.

אפשרות א' (הכי פשוטה ומהירה - 30 שניות, ללא קוד): Netlify Drop
--------------------------------------------------------------
1. חלצו את קובץ ה-ZIP הזה לתיקייה במחשב.
2. היכנסו לאתר: https://app.netlify.com/drop
3. גררו את התיקייה שחילצתם (או את הקובץ index.html) לתוך המסך.
4. תקבלו מיד קישור קבוע (למשל https://line411-parents.netlify.app) שאפשר לשלוח להורים בוואטסאפ!

אפשרות ב' (מומלצת ליציבות מקסימלית וללא חסימות דפדפן): Cloudflare Pages או Vercel
----------------------------------------------------------------------------------
1. היכנסו ל- https://pages.cloudflare.com או https://vercel.com
2. העלו את התיקייה (Upload Assets / Deploy).
3. אם מעלים ל-Vercel, הקובץ api/bus.js יופעל אוטומטית כשרת תיווך שמושך נתוני אמת של קו 411 ישירות מ-BusNearby ומ-Curlbus ללא שום מגבלת דפדפן.

איך להתקין בטלפון של ההורים ככפתור קבוע במסך הבית:
--------------------------------------------------
* באנדרואיד (Chrome): פתחו את הקישור -> לחצו על 3 הנקודות למעלה -> "הוספה למסך הבית" (Add to Home screen).
* באייפון (Safari): פתחו את הקישור -> לחצו על כפתור השיתוף למטה -> "הוספה למסך הבית" (Add to Home Screen).
